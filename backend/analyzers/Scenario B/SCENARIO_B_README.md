# scenario_b Analytics Backend

## Overview

This module implements the analytics backend for **Scenario B**:

> Comparing discussion trends of `war`, `tariff`, and `oil`
> across social media and news platforms.

The analytics system reads processed data directly from ElasticSearch and generates structured JSON outputs for visualization and frontend integration.

---

# Data Source

All analytics queries use the ElasticSearch index:

```text
social_posts
```

The following fields are already generated by the existing pipeline:

| Field      | Description                         |
| ---------- | ----------------------------------- |
| topic      | war / tariff / oil / general(ignore)|
| sentiment  | sentiment score                     |
| platform   | reddit / bluesky / gdelt / mastodon |
| created_at | timestamp                           |

# Analytics Files

## 1. topic_counts.py

### Purpose

Counts how many posts belong to each topic:

* war
* tariff
* oil

### Output Format

```json
{
  "status": "success",
  "scenario": "scenario_b",
  "metric": "topic_counts",
  "data": [
    {
      "topic": "war",
      "count": 1200
    }
  ]
}
```

### Usage

```python
from analytics.topic_counts import get_topic_counts

response = get_topic_counts()
```

---

## 2. topic_trends.py

### Purpose

Returns time-series topic trends grouped by week(It can be adjusted to "day" or "month" as needed)

Used for:

* trend line charts
* temporal analysis

### Output Format

```json
{
  "status": "success",
  "scenario": "scenario_b",
  "metric": "topic_trends",
  "interval": "week",
  "data": [
    {
      "date": "2026-04-21",
      "topics": {
        "war": 120,
        "oil": 55,
        "tariff": 30
      }
    }
  ]
}
```

### Usage

```python
from analytics.topic_trends import get_topic_trends

response = get_topic_trends()
```

## 3. platform_topic_distribution.py

### Purpose

Counts topic distribution for each platform.

Platforms include:

* reddit
* bluesky
* mastodon
* gdelt

Used for:

* grouped bar charts
* stacked charts
* platform comparison

### Output Format

```json
{
  "status": "success",
  "scenario": "scenario_b",
  "metric": "platform_topic_distribution",
  "data": [
    {
      "platform": "reddit",
      "topics": {
        "war": 120,
        "oil": 80,
        "tariff": 40
      }
    }
  ]
}
```

### Usage

```python
from analytics.platform_topic_distribution import get_platform_topic_distribution

response = get_platform_topic_distribution()
```

## 4. topic_sentiment.py

### Purpose

Calculates average sentiment score for each topic.

Used for:

* sentiment comparison charts
* topic emotion analysis

### Output Format

```json
{
  "status": "success",
  "scenario": "scenario_b",
  "metric": "topic_sentiment",
  "data": [
    {
      "topic": "war",
      "average_sentiment": -0.42
    }
  ]
}
```

### Usage

```python
from analytics.topic_sentiment import get_topic_sentiment

response = get_topic_sentiment()
```
